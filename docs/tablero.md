## Reglas de uso

- Cada tarjeta o Issue debe representar una tarea concreta.
- Cada tarea debe tener responsable y fecha compromiso.
- Cuando cambie el estado real de una tarea, debe moverse el mismo día.
- Al cerrar una tarea, debe agregarse un enlace a su evidencia: commit, Pull Request, documento o minuta.
- Evitar más de 2 tareas simultáneas "En curso" por persona.
- No marcar una tarea como "Hecho" si no existe evidencia verificable.
