## Regla
Cada referencia debe permitir localizar la evidencia en aproximadamente un minuto. Para commits registrar repositorio, rama, hash y mensaje; para tareas, número de Issue o tarjeta; para documentos, archivo y sección; para acuerdos, minuta y acuerdo correspondiente.
