# Sistema de Tareas de Empresa de Eventos

Proyecto académico para la materia **Gestión de Proyectos de Software**.

## Descripción

Sistema para apoyar a una empresa de eventos en la organización, asignación y seguimiento de tareas relacionadas con la planeación y ejecución de eventos.

La primera versión busca permitir:

- Registrar eventos.
- Crear y consultar tareas.
- Asignar responsables.
- Definir prioridad y fecha límite.
- Actualizar el estado de cada tarea.
- Consultar el avance general de las tareas de un evento.

## Forma de trabajo

- La rama principal es `main`.
- Cada tarea se desarrolla en una rama independiente.
- Nombres sugeridos de ramas: `feat/nombre-de-la-tarea`, `fix/nombre-del-error`, `docs/nombre-del-cambio`.
- Cada cambio debe tener un commit descriptivo.
- Antes de integrar una tarea a `main`, se debe abrir un Pull Request y solicitar revisión de otro integrante.
- La evidencia de cada tarea debe quedar ligada a su commit o Pull Request.
